# Pacific Northwest Flora & Fauna Guide

A comprehensive guide to Washington State species, including Indigenous names, scientific classification, and habitat information.

## Project Structure

- `data/` - Flora and fauna Python dictionaries
- `images/` - Species photographs
- `web/` - HTML/CSS/JS for webpage display
- `main.py` - Control script for exporting and searching

## Setup

```bash
python main.py show
python main.py export
```
